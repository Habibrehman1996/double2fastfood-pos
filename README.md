# Khan Saab POS — Streamlit

Run this Streamlit replacement of the Tkinter POS app.

Instructions:

1. (Optional) Create a virtualenv and activate it.
2. Install dependencies:

```bash
pip install -r streamlit_app/requirements.txt
```

3. Run the app from the project root:

```bash
streamlit run streamlit_app/app.py
```

The app reuses the existing `database.py` in the project root and will create `restaurant.db` automatically.
